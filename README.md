# SimpleOnlineClipboardManager

Простой веб-буфер обмена между телефоном и компьютером на Python и Flask. Устройства обмениваются текстом через две страницы, сообщения сохраняются в текстовых файлах.

## Запуск

```sh
python -m pip install flask
python -c "from pathlib import Path; [Path(p).touch(exist_ok=True) for p in ('from_phone.txt', 'from_comp.txt')]"
python app.py
```

Локально откройте `http://127.0.0.1:5000/phone` на стороне телефона и `/comp` на стороне компьютера. Короткие адреса — `/p` и `/c`.

Для доступа с другого устройства в своей сети запустите `python -m flask --app app run --host 0.0.0.0` и используйте локальный IP компьютера вместо `127.0.0.1`. Файлы сообщений должны находиться в рабочем каталоге процесса. Встроенной авторизации нет; этот вариант рассчитан на доверенную среду.
